# Real research repository pilot (not completed)

The repository manifest is deliberately unfilled. We have not verified or executed historical research repositories for this alpha release.

Each real case needs: source URL, frozen commit, license/permission, paper reference, framework, original environment, original dataset and split, observed breakage log, trusted baseline methodology, evaluation protocol, and reviewer ground truth.

Run unknown code **only** in isolated containers with restricted files, network and CPU/memory resources. A timeout subprocess is not a secure container. Keep original source unchanged. Exclude private datasets and credentials.

Controlled dataset validation lives separately at `validation/real_data_pilot.py`.
